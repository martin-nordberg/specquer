# New File Functionality

* In the left folder tree pane, add the ability to right click a folder and create a new file.
* The file name is entered in a modal dialog similar to file renaming.
* The file is created empty, added to the left pane, and then opened in the right pane.

# New Folder Functionality

* In the left folder tree pane, add the ability to right click a folder and create a new folder.
* The folder name is entered in a modal dialog similar to file renaming minus the ".md" text.
* The folder is created and added to the left pane.
